# Allowance

A personal spending tracker with a Monday–Sunday weekly budget.

**Use it:** open the site on your phone, then Share → Add to Home Screen (iPhone) or ⋮ → Add to Home screen (Android). It opens like an app and works offline.

**Your data:** expenses are saved on the device you enter them on. Nothing is sent anywhere except the date of a US dollar expense, to look up the Bank of Canada exchange rate. This repository only holds the app's code.

**Backups:** Settings → Download a full backup. Restore it on any device with Settings → Restore from a backup.
